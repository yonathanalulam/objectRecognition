This app acts like a set of digital eyes that can recognize specific items through your webcam in real-time. It uses an artificial intelligence called **YOLOv8** to scan every frame of video, specifically looking for people, phones, or spoons. Once it spots one of these objects, it instantly draws a colored box around it and labels it with a "confidence" percentage. It's built using **Python** and **OpenCV**, which handles the heavy lifting of displaying the video and drawing the graphics on your screen.

## 🚀 Features
* **Real-time Tracking:** Detects objects instantly with high accuracy.
* **Visual Labels:** Highlights people, phones, and spoons with unique colors.
* **Lightweight:** Uses the YOLOv8-nano model for smooth performance.
